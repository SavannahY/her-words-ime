你的词，由你决定。

记住常用的人名和英文。也可以忘记，或让一个名字不再出现在候选里。

添加一个词

在中文模式键入输入码，就能选到这个词。英文西文模式直接上屏，不会自动保存；可在这里手动添加。同一个词重新保存会修改它的输入码。

本地记忆

只记录本输入法里确认上屏的短词和输入码，不读取聊天框上下文。可以随时关闭自动记忆。

“忘记”撤销个性化记忆；基础词典仍可能有这个词。若不想再看到，请选择“不再推荐”，它也会拦住基础词典和组合候选。手动重新输入不会自动恢复已屏蔽的词。

不再推荐

恢复后，该词可以再次出现在候选里。你可以直接填写尚未记住、但不想再看到的名字。

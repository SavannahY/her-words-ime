# 本地中文语音转文字

从仓库根目录运行：

```sh
python3 scripts/serve_voice.py
```

用支持 `SpeechRecognition` 或 `webkitSpeechRecognition` 的浏览器打开 `http://127.0.0.1:8765`。点击「开始听写」并授权麦克风；可以停止、重新尝试、继续听写，在左侧编辑识别原文，再复制右侧结果。不支持语音识别的浏览器仍可手动输入文字。端口被占用时可加 `--port 8766`。

默认使用中性友好表达，也可以切换社群借字或保留措辞。三种模式的输出均将所有「他」改为「她」；左侧保留原文供校对。繁体选项仅选择词包的繁体替换结果，不是全文简繁转换器。

规则严格遵守同一词包的 `match`：`phrase` 可在句中替换，`exact` 仅在整个待处理文本恰好等于词条时替换。长句中不保证过滤所有相关词语，避免误改「你妈的生日」和「黑寡妇」等正常表达。可在左侧选中一个词，点击「仅处理选中文字」，右侧只输出该选区的转换结果，原文保留；点击「恢复处理全文」即可返回。社群借字是个人写法，不代表规范汉字或标准读音。

## 隐私与识别限制

文字改写在当前浏览器页面内完成。本地 Python 服务只提供固定静态资源和规则 JSON，不提供上传接口，不读取或保存听写文字，不记录请求日志；服务固定绑定 `127.0.0.1`。页面不使用 Cookie、浏览器本地存储、账号或分析服务。刷新、关闭或清空后不保留本页文字；主动复制会把结果放入系统剪贴板。

**语音识别不保证离线。** 浏览器可能把音频发送给其识别服务商，可能需要网络；麦克风权限、识别语言、可用性、准确率及服务商留存政策由浏览器和其服务决定。本页面没有自行录制音频，也没有将音频或文字上传到项目服务器。识别失败时会显示权限、设备或网络提示，可重新尝试。

实际听写需要在支持的浏览器中授权麦克风，并对识别结果人工校对。自动测试使用模拟识别事件，不调用真实麦克风，也不代表已验证所有浏览器的真实语音服务。可参见 [MDN 的 Web Speech API 说明](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API/Using_the_Web_Speech_API)；复制功能使用 [Clipboard.writeText](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText)，权限失败时会选中结果供手动复制。

## 规则来源与测试

服务启动时读取同一个 `language-packs.json`，调用系统输入法使用的 `compile_data()`，生成仅含数据的 JSON 规则并在 `/rules.json` 提供。页面不加载 Lua，不执行贡献者的代码；没有维护另一份手抄规则。修改词包后重启本地服务即可使用新规则。

需要独立 JSON 文件时：

```sh
python3 scripts/compile_web_rules.py --output /tmp/her-words-web-rules.json
```

Python 的编译和服务只需标准库。页面不需要外部 JS 库、构建工具或网络字体。以下测试中，浏览器模块和原有语音控制器事件测试另外需要 Node.js；未安装时这两项会明确跳过。

```sh
python3 -m unittest discover -s tests -p 'test_web_rules.py' -v
node web/verify-voice.mjs
```

规则测试直接使用共享词包里的正例和反例，并检查完整匹配边界、长词优先、字面匹配、不递归改写、繁体输出及独立「他→她」。服务测试验证只绑定回环地址、拒绝提交、拒绝路径穿越和非本机 Host。语音事件测试覆盖重复开始、临时结果更新、停止保留末句、取消后的旧回调、错误重试及销毁。

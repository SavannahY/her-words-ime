# 本地词库

个人词库与社区语言包是两类数据。社区贡献进入 GitHub；个人的人名、英文词、输入码、使用次数、最近使用时间和不再推荐名单只在本机保存，不会作为词包提交或上传。

## 日常使用

开启自动记忆后，只从本键盘已确认的短词学习，不读取聊天框前后文、联系人、剪贴板或历史消息。可以手动添加名字、英文词和对应的全拼／缩写。未确认或取消的组成不会作为记忆保存。

- **忘记**：删除该词的个人频率和输入关联。基础词典可能本来就有这个词；之后主动选用，也允许重新学习。
- **不再推荐**：删除相关个人记忆，同时保留一条本地隐藏偏好；基础词典、全拼、缩写和含有这个名字的组合候选也会被过滤，自动学习不会把它加回来。需要保留词本身作为隐藏名单，才能识别以后要避开的词。
- **恢复推荐**：移除隐藏偏好，不恢复已经删除的个人记忆。
- **清空已记住的词**：清除个人词语，保留隐藏名单，避免不想看到的名字重现。
- **关闭自动记忆**：停止新增学习，已有词语仍可使用、删除或隐藏。手动添加仍然可用。

中文隐藏词按字面包含关系匹配，例如隐藏“小芳”也会隐藏“给小芳留言”。英文忽略 ASCII 大小写，使用单词边界；隐藏 `Ann` 不会隐藏 `planning`。匹配不理解人物身份，同名的人不会自动区分。可以随时主动恢复。

## Mac

在「她说词库」窗口添加、搜索和管理词语；隐藏名单默认折叠。无需完整 Xcode 或语音模型，可使用 Apple Command Line Tools 编译：

```sh
python3 scripts/build_macos_word_memory_app.py
open dist/她说词库.app
```

若不构建原生窗口，也可从仓库运行备用管理页：

```sh
python3 scripts/manage_word_memory.py
```

浏览器打开 `http://127.0.0.1:8767`。该服务只监听本机，修改需要本页令牌与本机来源校验，不记录请求日志。关闭服务不影响输入法继续使用已保存的词库。

Mac 只在确认中文候选后自动记忆短词。西文直输不会自动捕获英文；可以手动添加 `GitHub`，输入码设为 `gh`，再在中文模式用 `gh` 选词。可以给人名指定完整拼音或喜欢的缩写。

数据在 `~/Library/Rime`：

- `her_memory_learned.tsv`：Rime 负责写入已确认短词。
- `her_memory_policy.tsv`：管理器负责写入手动词、记忆开关、隐藏词及删除时间截点。
- `her_memory_policy.lock`：管理端之间的写入锁，不包含词语。

管理器不与 Rime 同时改写同一数据文件；策略原子替换，下次组成候选时生效，无需为每次删除重启输入法。目录权限为 `0700`。管理器产生的策略文件为 `0600`；Lua 产生的学习文件及临时文件由私有目录保护。文件损坏或版本不支持时报告错误并保留文件，不静默重置；输入法在坏策略期间停止提供个人候选并沿用最后有效隐藏名单。

本方案关闭 Rime 原生 userdb 的使用和新增学习，让新学习统一接受这里的管理。以前的 Rime 数据库保留，但不参与她说方案的推荐；本功能不会清理 Apple 系统输入法或其他输入法的私人词库。

新版「她说语音」读取同一 Mac 词库，将允许的人名／英文词作为语音提示。隐藏词不会用作提示；真实录音仍可能识别出它们，原文会保留。语音转写不会自动被存成个人词库或聊天记录。

## iPhone

点击键盘顶部「词库」管理，或长按候选词进行忘记／不再推荐。面板使用本键盘输入名字和拼音／缩写；编辑词库不会向宿主聊天框插入文字。隐藏名单只有主动点开才显示。

中文会记住确认候选；同一完整拼音中分段选出的短姓名也可组合记忆。英文先在组成栏形成一个词，空格或换行确认原词，点击候选才使用补全；不会为了补全删除聊天框已有文字。网址、邮箱、数字和符号等限定输入框不提供个人候选或自动记忆。

文件位于键盘扩展自己的 Application Support/HerWordsKeyboardMemory/word-memory.json，文件权限 `0600`，最多 2,000 个词和 2,000 条隐藏偏好。无需完全访问、不联网、不使用 App Groups；iPhone 主 App 的语音功能无法读取键盘的私人词库，Mac 和 iPhone 也不自动同步。卸载主 App 会删除扩展数据；同一 Bundle ID 的续签应保留安装，避免先卸载。

离开键盘或更换文档会取消未确认组成。宿主 App 的异步文字／选区回调采用保守清空策略，可能清掉分段输入的剩余拼音；兼容性与触摸操作仍需在真实手机验证。不会为此读取或删除宿主上下文。

## 验证

共享 Swift 核心的独立检查覆盖本地持久化、学习开关、频率排序、英文与拼音补全、忘记、隐藏基础词及组合候选、阻止重新学习、恢复、容量、权限和坏文件保留。Mac 另外通过真实 librime 验证确认后学习、取消、不再推荐、恢复及重启。

```sh
python3 -m unittest discover -s tests -p 'test_word_memory_mac.py'
python3 tests/integration_word_memory.py
swiftc -swift-version 5 -O ios/Shared/*.swift ios/Tests/WordMemoryChecks.swift -o /tmp/her-memory-checks
/tmp/her-memory-checks
```

测试使用临时数据与虚构名字，不读取用户正在使用的个人词库。CI 的编译和引擎测试不代表已经在真实 iPhone 完成安装或触摸验收。

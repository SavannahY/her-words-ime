# Mac 三语输入与西语学习

先在 macOS 输入源中选中「鼠须管」，按 **Control＋反引号（`）** 打开方案菜单，选择：

- **她说 · 女性优先全拼**（`her_words`）：中文全拼及现有个人词库。
- **她说 · English**（`her_english`）：英文直接输入，保留大小写、空格和标点。
- **她说 · Español 西班牙语**（`her_spanish`）：西语输入及可选学习提示。

## 西语怎么输入

西语方案保留输入原拼写作为首项。需要带重音的词或短句时，主动选择建议；不会把 `si` 一律改成 `sí`，也不会把英文自动改成西语。

**Tab** 选择下一个候选，**Shift＋Tab** 选择上一个；也可用上下方向键。**空格**确认当前候选并输入一个真正的空格，因此连续打词不会粘在一起。短句建议也需要主动选择。

使用以下分号组合输入特殊字符：

| 输入 | 输出 | 输入 | 输出 |
|---|---|---|---|
| `;a` | á | `;A` | Á |
| `;e` | é | `;E` | É |
| `;i` | í | `;I` | Í |
| `;o` | ó | `;O` | Ó |
| `;u` | ú | `;U` | Ú |
| `;n` | ñ | `;N` | Ñ |
| `;v` | ü | `;V` | Ü |
| `;?` | ¿ | `;!` | ¡ |
| `;;` | ; | | |

例如，输入 `ma;nana` 可得到 `mañana`，输入 `caf;e` 可得到 `café`。按 `;?C;omo est;as?` 输入的结果是 `¿Cómo estás?`，其中的空格正常保留。问句和感叹句请同时保留开头、结尾的符号。

## 两个独立的学习开关

**西语候选旁的中文释义**：在西语方案中按 Control＋反引号打开菜单，选择「显示西语释义」或「隐藏西语释义」（`her_es_hints`）。首次安装默认显示，之后保存你的选择。释义只出现在候选旁，确认后只输入西语文字。

**用中文拼音查询已收录的西语表达**：切回中文方案，在同一菜单选择「开启中文查西语」或「关闭中文查西语」（`her_es_lookup`）。首次安装默认关闭；打开后，在原有中文候选之外增加对应的西语候选，需要主动选择。这两个开关互不影响，可以只开其中一个。

菜单显示的是**当前状态**，选中后会切换到箭头所示的新状态。中文方案若把选项折叠成「中／半／汉／。／友／关」一行，先选择这一行展开，再切换「中文查西语」。

开启中文查西语后，可以直接试这些完整拼音码：

| 中文查询 | 输入码 | 可选西语输出 |
|---|---|---|
| 你好 | `nihao` | `Hola.` |
| 谢谢 | `xiexie` | `Gracias.` |
| 不客气 | `bukeqi` | `De nada.` |
| 我是中国人 | `woshizhongguoren` | `Soy china.` |
| 我是中国男性 | `woshizhongguonanxing` | `Soy chino.` |
| 我正在学西班牙语 | `wozhengzaixuexibanyayu` | `Estoy aprendiendo español.` |
| 多少钱 | `duoshaoqian` | `¿Cuánto cuesta?` |
| 请您再说一遍 | `qingninzaishuoyibian` | `¿Puede repetir, por favor?` |

不需要时，在中文方案菜单选择「关闭中文查西语」；只想隐藏候选旁的中文说明，则到西语方案选择「隐藏西语释义」。

## 收录范围与个人词库

本地资料含 **69 个主条目、7 个性别或称呼变体，共 76 种西语输出和 86 个中文查询**。覆盖问候、自我介绍、语言学习、餐饮、出行及日常状态，离线使用。中文入口只查询这些明确收录的词句，不能任意翻译，也不提供自动语法纠错。A1／A2 标签是粗略学习提示。

需要性别配合的示例优先列女性形式，同时保留正确男性形式。例如 `Encantada` 随说话者变化，`Bienvenida` 随被欢迎的人变化；西语的语法性别和代词不会被全局替换。中文仍默认推荐「她／她们」，也保留「他／他们」供主动选用。

西语选词和英文直输不会自动写入中文个人记忆。手动添加人名、英文词及全拼／缩写，仍在「她说词库」中管理，并在中文方案使用；删除、忘记和不再推荐的方法见[本地词库指南](local-memory.md)。

「不再推荐」作用于候选及候选注释，也覆盖西语建议。手动键入的原文、粘贴内容和宿主应用已有文字由你控制；鼠须管失焦时可能直接提交尚在编辑的原文，因此这项设置不是整台电脑的文字拦截器。

## 来源与贡献

内容在 [data/spanish-learning.json](../data/spanish-learning.json)。每条保留 `source_ids`，对应 RAE／ASALE、Instituto Cervantes 等机构的直接页面，并区分常用表达、词头事实和依据语法自编的例句。中文释义和提示独立编写；没有整套复制课程或第三方词表。部分 Cervantes 原页核对时处于维护状态，来源记录明确标为官方索引片段。

贡献时补充自然的中文 `zh_queries`、逐字完整拼音及可追溯来源；西语使用 NFC、正确重音和标点。若存在性别或称呼变化，分别提供正确变体及明确查询，不凭替换词尾生成。中文查词码是收录入口，不必逐字对应整句翻译。

[编译器](../scripts/compile_spanish_learning.py)严格检查字段、来源、字符、输入码和拼音，生成只含静态数据的 [Lua 表](../rime/lua/her_spanish_data.lua)，并记录源文件 SHA-256。修改 JSON 后，在仓库根目录运行：

```sh
python3 scripts/compile_spanish_learning.py
python3 scripts/compile_spanish_learning.py --check
python3 -m unittest discover -s tests -p 'test_spanish_learning.py'
```

提交 JSON 与重新生成的 Lua 文件；不要手改生成物。
